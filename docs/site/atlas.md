## What the system will connect

```flow
Browser and client core | Present authorized snapshots, not a second source of authority.
Center and PostgreSQL | Validate commands and commit durable state, events and receipts together.
Artifacts and workers | Preserve immutable proof while isolating local execution; cloud execution follows in S2.
Agents and human review | The center answers selected-record questions; isolated project-main identities activate in S2. A human merges.
```

Only the fixture center/database and portable contract surface exist today. Production authentication, chat, artifacts, workers, agent sessions, cloud placement and native UI are planned. Memory belongs to durable reviewed records, not model context or a permanent sandbox.
