# Citation

An inline reference generated from a stored record ID that opens that exact revision. Carried by an underline in ink, not by colour.
The only clickable thing an agent can put in a sentence. A link the model wrote is plain text, permanently.

## States

Message revision, decision, evidence, knowledge in S2. Unresolved renders as plain text with no affordance.

## Do not

- Do not link an agent-produced URL.
- Do not resolve to a record's current state when the sentence meant an earlier revision.
