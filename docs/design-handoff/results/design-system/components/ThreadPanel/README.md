# ThreadPanel
A root message and its ordered replies, in the right pane on desktop and as its own route at 390. Ask center and Create task are available at thread level.
Opening moves focus to the heading; Escape closes and returns focus to the message that opened it. The release gates treat a stranded focus as a failure.
## States
Open; empty replies with one sentence saying what would change it; root tombstone, where the root is replaced by a sentence and the replies survive.
## Do not
- Do not trap focus without an Escape route.
- Do not render an empty thread as a blank pane.
