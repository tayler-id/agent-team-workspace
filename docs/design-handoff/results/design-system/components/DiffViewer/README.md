# DiffViewer

A read-only diff opened last in evidence review. Every hunk is mapped to the acceptance item it supports or labelled unmapped; unmapped is never hidden or assumed harmless.
Added and removed lines carry a gutter glyph as well as their soft background, so the diff survives greyscale. At 390 it is its own route.

## Do not

- Do not open the diff first.
- Do not rely on background alone to mark a line.
