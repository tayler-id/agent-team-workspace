# RoomHeader
The room crumb, lifecycle chip, the project agent shown as `not_enabled`, member count and repository, with search at the right.
The crumb is two-tone: the project in grey, the room in ink. Lifecycle comes before anything else because a paused or archived room changes what every control beneath it means.
## States
Active; paused, naming who and when and the consequence for launching; archived, read-only, in the hist chip; onboarding blocked with the reason code and the action that clears it.
## Do
- Name the project agent even when it is not enabled.
- State the consequence of a lifecycle state, not just its name.
## Do not
- Do not grey out an archived room's content; only the chip says so.
- Do not call a room a channel.
