# Composer
Text entry for a room: safe Markdown, mentions, code fences, attachments; Enter sends and Shift+Enter breaks, as a reversible preference. Drafts survive route changes.
A soft `surface-inset` box with a toolbar row. The toolbar shows which agents are present as stacked marks. Ask center and Create task sit above it as soft pills; neither acts without its preview.
## States
Idle, typing, over limit refused before sending with the size named, offline with the draft visibly kept, rate limited with the retry interval, disabled for observers with the reason, and steering mode where the box says what a prompt cannot do before you type.
## Do
- Keep the send control visible and disabled with its reason beside it.
- Name limits as numbers: 16 KiB, 20 mentions, ten attachments.
## Do not
- Do not accept a secret here; secret entry is a dedicated masked form.
- Do not show a privileged command as accepted while offline.
