# MemberRoleControls
The member list with a role selector per person that shows the exact subject, last-owner protection, and a destructive preview that names what ends and what cannot be recalled.
Workspace roles: owner, member, observer. Project roles: maintainer, contributor, observer. Every destructive label names its subject.
## Do not
- Do not allow a revocation without a preview and a receipt.
- Do not hide a control blocked by last-owner protection; disable it and say why.
