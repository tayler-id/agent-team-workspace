# SearchResult
One row per hit with kind, snippet or title, room and time. Access is filtered before ranking, so there is never a redacted row or a count that includes records the reader cannot open. 50 per page.
## Kinds
Message, answer, task, evidence, decision; knowledge in S2. Each keeps the mark it has in the room.
## Do not
- Do not let a snippet be model-generated.
- Do not show a placeholder for a record the reader cannot open.
