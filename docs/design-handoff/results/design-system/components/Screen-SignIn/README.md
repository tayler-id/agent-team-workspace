# Screen-SignIn
Step 1 of the story: invitation and sign-in, single column at 1440.
Magic link only, ten-minute expiry, five links per email per hour, no public sign-up. The invitation names the workspace, role, inviter and expiry, and says that accepting creates exactly one membership and that project access is a separate grant. Denials are sentences, not red fields: wrong email, expired, already accepted.
