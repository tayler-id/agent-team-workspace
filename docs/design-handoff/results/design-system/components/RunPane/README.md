# RunPane
Follow one run: a sticky head with committed state, the numbered immutable stream, cleanup state, budget used of reserved, and the steering composer.
The head is right when it disagrees with the stream. Late events from a stale worker land in the stream labelled historical and cannot satisfy a gate. A truncated output shows a marker line.
## Do
- Number every activity; the sequence is part of the record.
- Show used of reserved, never a percentage alone.
- Say before typing that steering is immutable and cannot widen scope, tools, payer or placement.
## Do not
- Do not derive the head from the stream.
- Do not show a steering control on a terminal run.
