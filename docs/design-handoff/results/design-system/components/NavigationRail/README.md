# NavigationRail
One landmark listing rooms, live runs with their agents' marks, and the inbox, with counts as neutral chips. Presence sits on people.
Runs get their own section because the packet lists them in the rail. Each live run shows the delegate's pastel mark and a state dot, so the rail reads like the room does. Unread counts come from the last seen room sequence and use the violet live dot.
## States
Expanded; collapsed to marks with identical accessible names; a four-destination bottom bar at 390. Offline, resync required and revoked replace the foot with a sentence that says what the client will do.
## Do
- Keep it one landmark, every destination keyboard reachable.
- Truncate a long room name; the full name lives in the header.
- Keep the active row a neutral `surface-inset` pill with heavier type. Never a coloured bar.
## Do not
- Do not show presence on a machine or an agent.
- Do not colour a run row by state; the dot carries it.
