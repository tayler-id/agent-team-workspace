- Reuse timeline semantics, keyboard focus handling, bounded row rendering, composer draft projection and neutral CSS where tests prove them suitable. Remove fixture-only controls from the usable route, not from the preservation record.

Browser operations must use the approved `chrome-devtools-axi` route; project-owned scripted verification must report its real instrument and limitations.
- Add no final branding, visual tokens, decorative language or redesign of the accepted documentation content. The design team owns final visual presentation.
